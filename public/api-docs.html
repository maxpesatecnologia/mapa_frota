API Mapa Frota Maxpesa

v1 · REST, somente leitura, JSON

URL base: https://mapa-frota.vercel.app/api/v1

Autenticação

Toda chamada precisa da chave de API, fornecida separadamente pela Maxpesa. Envie em um dos headers:

x-api-key: <SUA_CHAVE>
Authorization: Bearer <SUA_CHAVE>

Sem chave ou com chave errada, a resposta é 401. Só o método GET é aceito.

Recursos

GET /api/v1 lista os recursos. Cada um fica em GET /api/v1/{recurso}.

RecursoConteúdo
programacaoProgramação diária por placa e data (status, cliente, operador, horários, quebras, motivo, km)
programacao_anexosMetadados dos anexos de cada programação (programacao_id, nome_arquivo, storage_path, tipo_arquivo, tamanho_bytes)
equipamentosCadastro de equipamentos (placa, frota, equipamento, família)
clientesCadastro de clientes
operadoresCadastro de operadores
status_programacaoCódigos de status da programação
motivosMotivos de parada/quebra
itens_motivoItens de cada motivo

Parâmetros

ParâmetroDescrição
limitRegistros por chamada. Padrão 500, máximo 1000
offsetPosição inicial (paginação). Padrão 0
data_ini, data_fimSó em programacao. Formato AAAA-MM-DD, limites inclusivos
qualquer colunaFiltro de igualdade, ex.: ?placa=ABC1234 ou ?programacao_id=<uuid>

Os filtros se combinam (E lógico). Uma coluna inexistente retorna 400.

Resposta

{
  "recurso": "equipamentos",
  "total": 87,
  "limit": 500,
  "offset": 0,
  "proximo_offset": null,
  "data": [ { "id": "...", "placa": "ED-10-012", "...": "..." } ]
}

total é o número de registros que atendem aos filtros. proximo_offset é o offset da próxima página, ou null quando acabou.

Paginação

Repita a chamada usando proximo_offset como offset até ele vir null. A programacao tem cerca de 25 mil registros: uns 25 requests com limit=1000.

Exemplos

# Equipamentos
curl -H "x-api-key: $CHAVE" "https://mapa-frota.vercel.app/api/v1/equipamentos?limit=10"

# Programação de uma placa em agosto de 2026
curl -H "x-api-key: $CHAVE" \
  "https://mapa-frota.vercel.app/api/v1/programacao?placa=ABC1234&data_ini=2026-08-01&data_fim=2026-08-31"

# Anexos de uma programação
curl -H "x-api-key: $CHAVE" \
  "https://mapa-frota.vercel.app/api/v1/programacao_anexos?programacao_id=<uuid>"
import requests

BASE = "https://mapa-frota.vercel.app/api/v1"
H = {"x-api-key": CHAVE}

def buscar_tudo(recurso, **filtros):
    offset, tudo = 0, []
    while offset is not None:
        r = requests.get(f"{BASE}/{recurso}", headers=H,
                         params={"limit": 1000, "offset": offset, **filtros})
        r.raise_for_status()
        j = r.json()
        tudo += j["data"]
        offset = j["proximo_offset"]
    return tudo

programacao = buscar_tudo("programacao", data_ini="2026-08-01")

Códigos de erro

CódigoMotivo
400Coluna de filtro inválida ou erro na consulta
401API key ausente ou inválida
404Recurso inexistente
405Método diferente de GET
500Servidor sem configuração

Observações

  • Os dados são lidos em tempo real do banco; não há cache.
  • Os anexos retornam só os metadados e o caminho (storage_path), não o arquivo.
  • Campos de horário (inicio_operacao, fim_operacao, total_horas etc.) são texto, não número.
